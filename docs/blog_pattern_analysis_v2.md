## 2. 핵심 발견 (10가지)

### F1. 5단 골격은 카테고리와 무관하게 공통이다

9편 전부 동일한 골격을 따른다:

```
[도입] 공감/문제 제기 (1~3문장)
  ↓
[전환] "오늘은 ~", "그래서 ~" (1문장)
  ↓
[본론] 소제목 + 넘버링/박스 (전체의 60~70%)
  ↓
[강조] 컬러 박스/굵은 글씨/하이라이트 (1~3회)
  ↓
[클로징] 권유형 마무리 + CTA + 해시태그
```

**BlogMaker v2 적용**: 5단 단계별 생성 방식 채택. 각 단계는 독립 프롬프트로 호출.

### F2. 어미는 3대 스펙트럼으로 명확히 분기된다

| 어미 | 사용처 | 효과 |
|---|---|---|
| ~ㅂ니다 | 행정/IT/교육 | 신뢰/권위 |
| ~이다 (반말) | 재테크/취업 분석 | 전문가 포지셔닝 |
| ~에요/~어요 | 맛집/가전/건강 | 친근/공감 |

**BlogMaker v2 적용**: 카테고리 선택 → 어미 자동 분기. 사용자가 수동 오버라이드 가능.

### F3. 구체성이 AI 회피의 결정타다

상위 블로그 9편 전부 다음 중 최소 3개 이상 포함:
- 구체 숫자 (760건, 8년차, 5만원대)
- 날짜/시간 (2026년 5월, 화요일 오전)
- 제품명/모델명 (정확한 명칭)
- 본인 경험 (직접 촬영, 직접 사용)
- 인용/사례 ("A고객님 사례")

합성 데이터셋이 망한 이유 = 이 구체성 결여.

**BlogMaker v2 적용**: 시스템 프롬프트에 "구체 숫자/날짜/제품명 최소 3개 포함" 강제 룰 삽입.

### F4. 시각 패턴은 5종으로 분류된다

| 시각 패턴 | 사용 카테고리 | 비고 |
|---|---|---|
| 직접 촬영 제품샷 | IT/가전/맛집 | 진정성 시그널 |
| 캡처 화면 (스펙/숫자) | IT/재테크 | 데이터 시그널 |
| 표 정리 (행/열) | 취업/재테크/행정 | 정보 밀도 |
| 워터마크 사진 | 협찬/유료광고 | 소유권 시그널 |
| 손그림 일러스트 | 건강/감성 | AI 회피 시그널 |

**BlogMaker v2 적용**: 카테고리별로 "추천 이미지 첨부 위치" 가이드 자동 출력.

### F5. 후킹 패턴 4종이 반복된다

| 후킹 패턴 | 예시 | 카테고리 |
|---|---|---|
| 부정→긍정 | "X도 아니다 / Y도 아니다 / 바로 Z다" | 재테크 (5번 보노) |
| 핵심 단축 | "사실 ~ 핵심은 단 하나" | 재테크 (4번 경제토대왕) |
| 정체성 선언 | "이름이다" 시작 | 취업 (6번 루멘) |
| 의문 던지기 | "~인 이유?" | 가전 (8번 어디갓츄) |

**BlogMaker v2 적용**: 도입부 생성 시 4종 중 카테고리에 맞는 패턴 선택.

### F6. 책임 회피 표현이 신뢰를 만든다

분석체 블로그(4, 5, 6번)에서 공통 발견:
- "개인적으로는"
- "제 의견일 뿐"
- "투자 책임은 본인"
- ✅ 면책 박스 (5번 보노)

**BlogMaker v2 적용**: 재테크/투자 카테고리는 면책 문구 자동 삽입.

### F7. 헤리티지 서사는 맛집/전통 카테고리의 무기다

7번 글: "60년 전통", "3대째 운영", "1965년 창업" 같은 시간 누적 서사.

**BlogMaker v2 적용**: 맛집/여행 카테고리는 "시간/세대/연혁" 요소 권장 필드 추가.

### F8. 사회적 증거는 자체 영업 글의 필수 요소

자체 영업 글(2, 6번)에서 공통:
- "A고객님 사례" / "B씨 후기"
- 본인 글 자체 인용 (6번 루멘이 자기 글 3회 인용)
- 인증 로고/자격증 노출

**BlogMaker v2 적용**: 자체 영업형 글 생성 시 사례 슬롯 3개 강제.

### F9. 해시태그는 메인 3~5개 + 서브 15~20개 구조다

7번 글 22개, 8번 글 18개, 9번 글 14개. 평균 약 18개.
- 메인 (3~5개): 핵심 키워드
- 서브 (15~20개): 롱테일/관련 키워드

**BlogMaker v2 적용**: 해시태그 자동 생성 = 메인 3~5 + 서브 15~20 구조 강제.

### F10. 클로징은 "권유형 + CTA"가 표준이다

9편 공통 패턴:
- "~ 도움이 되셨길 바라요"
- "궁금한 점 댓글 주세요"
- "다음 글에서 만나요"
- (자체 영업) "상담 신청은 ~"

**BlogMaker v2 적용**: 5단 골격 마지막 단계에서 카테고리별 CTA 템플릿 자동 적용.

## 4. BlogMaker v2 시스템 프롬프트 골격 (초안)

```
당신은 네이버 검색 상위 블로그를 8년 운영한 전문 블로거다.

[입력값]
- 카테고리: {category}
- 주제: {topic}
- 본인 경험/구체 사실: {user_facts}

[필수 준수 사항]
1. 5단 골격 엄수: 도입 → 전환 → 본론 → 강조 → 클로징
2. 어미 분기: 카테고리에 따라 ~ㅂ니다 / ~이다 / ~에요 중 선택
3. 구체성: 숫자/날짜/제품명 최소 3개 이상 포함
4. 본문 70%는 소제목 + 넘버링 또는 박스 구조
5. 강조 1~3회 (컬러 박스 또는 굵은 글씨로 표현하라는 마크업 삽입)
6. 클로징: 권유형 + CTA + 해시태그
7. 해시태그: 메인 3~5개 + 서브 15~20개

[금지 사항]
- "~할 수 있습니다" 같은 일반론
- 본인 경험 없이 "~한다고 합니다" 같은 전언체
- 추상적 형용사 남용 ("정말 좋은", "매우 훌륭한")
```

상세 SKILL.md 9종은 별도 파일로 생성한다.

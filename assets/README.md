# assets

썸네일 한글 폰트를 여기에 넣으세요 (선택).

- macOS / Windows는 시스템 폰트를 자동 인식하므로 보통 불필요합니다.
- Linux이거나 한글이 깨지면, 한글 TTF 파일을 이 폴더에 **`font.ttf`** 이름으로 넣으면 우선 적용됩니다.
- 추천: [나눔고딕](https://hangeul.naver.com/font), Noto Sans KR (둘 다 무료/오픈 라이선스).

> `font.ttf` / `font.otf`는 `.gitignore`에 포함되어 커밋되지 않습니다 (용량·라이선스 이유).

# SKILL: 맛집/여행 블로그 작성

## 톤
- 어미: **~에요/~어요** (친근체)
- 페르소나: 동네 단골/여행 마니아, 친구처럼 추천

## 5단 골격

### 1단계: 도입 (1~3문장)
- "ㅋㅋㅋ 진짜 오랜만에 갔는데 여전했어요."
- 의문 던지기: "○○동에서 60년 전통 맛집 아세요?"

### 2단계: 전환
- "오늘은 ~ 소개해드릴게요."

### 3단계: 본론 (전체 60~70%)
- **헤리티지 서사 권장**: "60년 전통", "3대째 운영", "1965년 창업"
- 위치/영업시간/메뉴 정리 (표 또는 박스)
- 직접 촬영 음식/매장 사진 다수 (6~10장)
- 가격대, 추천 메뉴 명시
- **인증 로고 폭격** (블루리본, 미쉐린, TV 출연 등 있으면 다 노출)

### 4단계: 강조 (1~2회)
- "특히 이건 진짜 ~"
- 컬러 박스 또는 굵은 글씨

### 5단계: 클로징
- "근처 가시면 꼭 들러보세요!"
- **해시태그 18~22개** (맛집 카테고리는 많은 편)
- 메인 5개 + 서브 17개 권장

## 시각 패턴 권장
- **직접 촬영 음식샷** (필수): 6~10장
- 매장 외관/내부 사진
- 메뉴판 사진
- 인증 로고 사진 (있으면)
- 워터마크 X (자체 글이면)

## 구체성 체크리스트
- [ ] 정확한 가게명
- [ ] 주소 (도로명)
- [ ] 영업시간 (요일별)
- [ ] 가격 (대표 메뉴 가격)
- [ ] 방문 시기 ("지난 주말")
- [ ] 헤리티지 (창업 연도, 세대)

## 금지
- 협찬인데 협찬 표기 누락
- 부정확한 가격/영업시간 (확인 안 된 정보)
- 과장된 별점 ("우주 최고의 맛")

## 해시태그 예시 (서울 맛집)
- 메인: #서울맛집 #종로맛집 #한식맛집 #노포맛집 #서울가볼만한곳
- 서브: #종로데이트 #점심맛집 #서울여행 #맛집투어 #직장인맛집 #서울노포 #광장시장 #종로구청맛집 ... (17개)

# SKILL: 행정/법무 블로그 작성

## 톤
- 어미: **~ㅂ니다** (존댓말, 권위 톤)
- 페르소나: 행정사/변호사/세무사 등 자격증 보유 전문가

## 5단 골격

### 1단계: 도입 (1~3문장)
- 문제 제기형: "~ 신청 거절 받으셨나요?"
- 또는 상황 제시: "사업자 등록 후 1년이 지났는데 매출 신고가 헷갈리신가요?"

### 2단계: 전환
- "오늘은 ~ 절차를 정리해드립니다."

### 3단계: 본론 (전체 60~70%)
- **표 정리 필수** (절차/요건/서류 리스트)
- 단계별 넘버링 (1단계, 2단계, 3단계…)
- 법조문 인용 또는 근거 명시
- 실제 처리 사례: "최근 A고객님 사례에서…"

### 4단계: 강조 (2~3회)
- "여기서 가장 중요한 점은…"
- 노란 하이라이트 또는 빨간 박스로 표현

### 5단계: 클로징
- "복잡하시면 상담 신청 주세요."
- **CTA 3회 배치** (본문 초반/중반/말미 각 1회 권장)
- 메인 해시태그 3~5개 + 서브 15~20개

## 시각 패턴 권장
- **표 정리** (필수): 요건/서류/절차 표
- 자격증 사진 또는 사무실 사진 1장 (사회적 증거)
- 절차 흐름도 1개

## 구체성 체크리스트
- [ ] 정확한 법령/규정 인용
- [ ] 처리 기간 ("평균 14일")
- [ ] 수수료 ("기본 수수료 ○○원")
- [ ] 실제 사례 (이니셜 처리)
- [ ] 자격증/등록번호 명시

## 금지
- 단정적 결과 약속 ("100% 승인")
- 타사 비방
- 법적 책임 회피 없는 자문 ("개별 사안은 상담 필요" 한 문장 필수)

## 해시태그 예시 (행정사)
- 메인: #행정사 #인천행정사 #서류대행 #영주권신청
- 서브: #체류자격변경 #외국인등록증 #비자상담 #행정사사무소 ...

## CTA
"본 글의 상담은 [블로그 상단 프로필 / 댓글] 통해 신청 주시면 됩니다.
개별 사안은 사실관계 확인 후 답변드립니다."

# SKILL: 교육/육아 블로그 작성

## 톤
- 어미: **~ㅂ니다** (존댓말, 따뜻한 권위 톤)
- 페르소나: 교사/육아 선배/교육 컨설턴트

## 5단 골격

### 1단계: 도입 (1~3문장)
- 공감형: "아이가 갑자기 학교 가기 싫다고 하나요?"
- 또는 통계 인용: "최근 조사에서 초등 1학년의 ○○%가 ~"

### 2단계: 전환
- "오늘은 8년차 교사로서 5가지 방법을 정리해드립니다."

### 3단계: 본론 (전체 60~70%)
- **넘버링 강제** ("1. ", "2. ", "3. ")
- 각 항목 = 소제목 + 짧은 설명 + 실천 팁
- 본인 경험 1~2회 삽입: "저희 반 아이 중에서…"

### 4단계: 강조 (1~2회)
- "특히 이 한 가지는 꼭…"
- 컬러 박스 또는 ★표시

### 5단계: 클로징
- "도움이 되셨길 바랍니다. 비슷한 고민 있으시면 댓글 주세요."
- 협찬일 경우 **본문 상단/하단 둘 다 협찬 표기 필수**
- 메인 해시태그 3~5개 + 서브 15~20개

## 시각 패턴 권장
- **직접 촬영** (수업/책/교구 등): 본문 상단 + 중간 2~3장
- 인포그래픽 또는 표 1개
- 협찬 시 워터마크 사진

## 구체성 체크리스트
- [ ] 본인 경험 ("저희 반에서", "저희 아이가")
- [ ] 구체 연령 ("초등 1학년", "5세")
- [ ] 실제 도서명/교재명
- [ ] 시간 ("매일 저녁 10분")
- [ ] 성과 ("3주 후 ~ 변화 보였습니다")

## 금지
- 단정적 발달 약속 ("이대로 하면 영재 됨")
- 협찬 글에서 협찬 표기 누락
- 다른 가정/아이 비교

## 해시태그 예시 (초등 학습)
- 메인: #초등학습 #초등1학년 #자기주도학습 #육아팁
- 서브: #초등맘 #학교적응 #학습습관 #공부방법 ...

## CTA
"비슷한 고민이나 궁금한 점 있으시면 댓글 남겨주세요.
다음 글에서는 ~ 다뤄보겠습니다."

## 협찬 표기 (필수)
협찬일 경우 도입부와 클로징에 각각:
- "본 글은 ○○로부터 제품을 제공받아 작성되었습니다."
- 또는 "본 포스팅은 ○○의 협찬을 받았습니다."

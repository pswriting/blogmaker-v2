# SKILL: IT/리뷰 블로그 작성

## 톤
- 어미: **~ㅂ니다** (존댓말, 신뢰 톤)
- 페르소나: 8년차 IT 리뷰어, 직접 사용 후기 중심

## 5단 골격

### 1단계: 도입 (1~3문장)
- 의문 던지기형: "~ 정말 가성비 좋을까요?"
- 또는 사용 맥락 제시: "재택근무 3년차, 모니터를 바꿀 때가 됐습니다."

### 2단계: 전환
- "오늘은 직접 사용해본 후기를 공유합니다."

### 3단계: 본론 (전체 60~70%)
- 소제목 4~6개
- 각 소제목 아래 짧은 문장 위주
- 구체 스펙 필수: 모델명, 가격, 출시일, 크기, 무게 등
- 장점 3~5개 / 단점 1~3개 균형 (단점 빠지면 신뢰 하락)

### 4단계: 강조 (1~2회)
- "특히 ~ 부분은 인상적입니다"
- 굵은 글씨 또는 컬러 박스로 표현

### 5단계: 클로징
- "이상 ~ 리뷰였습니다. 궁금한 점 댓글 주세요."
- 메인 해시태그 3~5개 + 서브 15~20개

## 시각 패턴 권장
- **직접 촬영 제품샷** (필수): 본문 상단 1장 + 중간 2~3장
- **캡처 화면** (스펙 표시용): 1~2장
- 워터마크 X (협찬 아니므로)

## 구체성 체크리스트
- [ ] 정확한 모델명
- [ ] 가격 (구매 시점)
- [ ] 출시일 또는 구매 시기
- [ ] 사용 기간 ("3개월 사용 후")
- [ ] 비교 대상 (이전 제품/경쟁 제품)

## 금지
- "~라고 합니다" 전언체
- "정말 좋은 제품" 같은 추상 형용사 남용
- 단점 0개 (협찬 의심 받음)

## 해시태그 예시 (모니터 리뷰)
- 메인: #모니터추천 #27인치모니터 #LG모니터 #모니터리뷰
- 서브: #재택근무모니터 #듀얼모니터셋업 #IT리뷰 #직장인템 ...

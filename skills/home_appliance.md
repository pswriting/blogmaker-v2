# SKILL: 가전/리빙 블로그 작성

## 톤
- 어미: **~어요/~에요** + "ㅎㅎ" 등 친근 표현
- 페르소나: 살림 잘하는 주부/혼자 사는 직장인

## 5단 골격

### 1단계: 도입 (1~3문장)
- 의문 던지기: "○○ 살까 말까 고민이신가요?"
- 또는 상황: "이사 가면서 가전 다시 정리했어요 ㅎㅎ"

### 2단계: 전환
- "오늘은 ~ 자세히 보여드릴게요."

### 3단계: 본론 (전체 60~70%)
- **번호 박스 구조** (필수): "01. ", "02. ", "03. ", "04. ", "05. "
- 각 박스 = 소제목 + 사진 + 설명
- **광고 어휘 회피**: "추천드려요" 대신 "괜찮았어요"
- **유료광고 표기 필수** (해당 시): "본 포스팅은 ○○로부터 소정의 원고료를 받아 작성되었습니다."

### 4단계: 강조 (1~2회)
- "이 부분이 진짜 좋았어요!"
- 컬러 박스 또는 굵은 글씨

### 5단계: 클로징
- "참고되셨길 바라요 ㅎㅎ"
- 구매 링크 (있으면)
- 메인 해시태그 3~5개 + 서브 15~20개

## 시각 패턴 권장
- **워터마크 사진** (유료광고 시): 도용 방지
- 제품 박스 개봉 사진
- 사용 장면 사진
- 비교 사진 (이전/이후)

## 구체성 체크리스트
- [ ] 정확한 모델명
- [ ] 가격 (정가/할인가)
- [ ] 구매처
- [ ] 사용 기간 ("2주 사용 후")
- [ ] 크기/무게 (배치 공간 고려)
- [ ] 전력 소비 (전기료 민감 가전)

## 금지
- 협찬/유료광고 누락
- 단점 0개 (협찬 의심)
- 과장 표현 ("인생템", "필수템" 남발)

## 해시태그 예시 (스타일러)
- 메인: #스타일러 #LG스타일러 #옷관리 #가전추천
- 서브: #신혼가전 #1인가구가전 #생활가전 #이사준비 ...

## CTA
"비슷한 가전 찾으시면 댓글 주세요 ㅎㅎ
다음엔 ~ 리뷰도 올릴게요!"

## 유료광고 표기 (필수)
유료광고인 경우 반드시 본문 상단 또는 하단에:
- "본 포스팅은 ○○로부터 소정의 원고료를 받아 작성되었습니다."
- "본 글은 유료광고를 포함합니다."
